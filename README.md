# IKCON Business Website

A modern and responsive business website created using **HTML, CSS, and JavaScript**.

## About

IKCON is a business website designed to showcase cosmetics, skincare, perfumes, and personal-care products. The website provides customers with information about the business, its products, and an easy way to get in touch.

## Features

* Responsive design
* Home section
* About section
* Products and services section
* Contact section
* Mobile navigation
* Interactive contact form
* Call and WhatsApp contact buttons

## Technologies Used

* HTML5
* CSS3
* JavaScript
